01 / GET STARTED

Your first figure in five steps

Start with the sample data, or import a CSV/TSV file. Changes in the figure editor appear in the live preview.

  1. Choose a chart. In Plot gallery, search for “volcano”, “scatter”, or another chart family. Choose one of the ten design presets.
  2. Load data. Open Data workspace, upload CSV/TSV, or paste a table with headers into the editor.
  3. Map columns. Assign the relevant X, Y, and group columns. Check the preview for meaningful axis ranges and units.
  4. Customize. Use Figure editor to adjust chart title, axes, palette, and rendering controls.
  5. Export. Use the preview’s export control or Publication export for a journal-size graphic.
Tip: For a quick tour, select a chart with its built-in sample dataset first. Import real data once you understand its required columns.
02 / DATA

Import & prepare data

The application accepts CSV and TSV for plotting. A header row names each variable. Numeric columns should use plain numbers; missing values and nonnumeric text can prevent a chart or statistical test from rendering.

Example: differential expression CSV
gene,log2FC,pvalue
GeneA,2.4,0.00004
GeneB,-1.8,0.003
GeneC,0.2,0.62
GeneD,1.3,0.024

Recommended formatting

  • One observation per row; unique column names in the first row.
  • Use decimal points and numeric p-values (e.g. 0.001, not p<0.001).
  • Provide relevant units and group identifiers as separate columns.
  • For very large datasets, downsample for previews and independently validate the full analysis.

For phylogenetic trees, use Newick text instead of a numeric table; see the Bioinformatics suite.

03 / CHART GALLERY

Plot styles & figure editor

There are 450 selectable configurations: 45 chart families combined with 10 visual presets. These are not 450 distinct statistical algorithms. Search and filter by chart family, then select a design and inspect the live plot.

◈

Basic & statistical

Scatter, bar, line, distributions, box/violin, correlation and related figures.

◎

Omics & biological

Volcano, Manhattan, enrichment, heatmaps, PCA and other research graphics.

▦

Publication themes

Ten designs change colors and visual styling without changing underlying data.

The editor allows you to map data columns, set titles and axis labels, adjust styling and save projects locally. Always check that the chosen chart makes statistical sense for your dataset.

04 / MODULE

Multi-panel figure editor

Combine existing charts into a single composite figure for papers and presentations.

  1. Make a chart in the gallery and click Figure composer in the sidebar or research cards.
  2. Choose Add current chart to capture the plotted figure.
  3. Switch to another chart family or data view and add more panels.
  4. Reorder panels, edit labels/captions (A, B, C), choose 1–3 columns and an aspect ratio.
  5. Export a combined SVG or PNG, or use browser printing to save a PDF.
Check text sizes and embedded SVG compatibility in your target journal or vector editor before submission.

06 / MODULE

Offline plotting assistant

Describe the chart you want using natural language. The assistant recognizes common plotting keywords, palette names and supported columns to configure the workspace.

Example requests
Create a volcano plot using log2FC and pvalue.
Make a scatter plot with a blue color palette.
Show a heatmap for the expression data.
  1. Open Plot assistant.
  2. Type a request describing the chart and fields.
  3. Apply the suggested settings, then verify the preview.
Important: This is a deterministic, rule-based assistant. It does not call a generative AI model, infer scientific conclusions, or automatically perform a complete data analysis.

08 / MODULE

Batch plot generation

Generate multiple chart-and-theme combinations from your current dataset and download a ZIP.

  1. Import your data and check the mapped columns.
  2. Open Batch generation.
  3. Select chart families and themes (up to 30 combinations per batch).
  4. Start generation and download the ZIP.
  5. Check the included manifest for skipped or incompatible chart combinations.

Batch archives include vector SVG plots, Plotly JSON configurations, source CSV and a manifest. Complex charts and large datasets can take more time and browser memory.

11 / REFERENCE

Saved projects & reproducibility

Use Saved projects for browser-local working copies. Export a project JSON if you want to move it to another computer, preserve the settings, or back it up. Browser storage can be cleared and is not a cloud backup.

For a publication workflow, archive the source CSV, plotted SVG/TIFF, Plotly JSON and exported Python reproduction script together with the statistical report.

12 / HELP

Frequently asked questions

My plot is empty. What should I check?

Confirm that your CSV has a header, the selected X/Y columns exist, numeric fields are actually numeric and the chart family matches your data. Try the built-in sample dataset for that chart.

Why does a batch skip some chart styles?

Not all plot families support the same data structure. The manifest reports incompatible combinations; choose suitable chart families and column mappings.

Can this compute UMAP from an H5AD file?

No. Import CSV coordinates exported from Scanpy or another analysis tool. The current UMAP module visualizes existing embeddings rather than reading H5AD or computing embeddings.

Can I use the plot assistant without an API key?

Yes. It runs offline using pattern-based rules and requires no external model service.

Why can’t I get a standalone PDF file directly?

The current PDF workflow uses the browser's printing system. Choose Print and select Save as PDF.

Why is my TIFF too large to export?

Large figure dimensions at 600 DPI may exceed the browser's 24-megapixel safety cap. Reduce dimensions or choose 300 DPI and validate journal requirements.

Are my datasets uploaded to a remote server?

In this version, plotting and calculations run locally in your browser. The deployed site serves application assets; saved projects are browser-local. Check your organization's rules before handling sensitive data in any web app.

13 / IMPORTANT

Limitations, privacy & responsible use

  • No hosted accounts, cloud synchronization, remote computational jobs or integrated generative AI model.
  • Statistics must be checked against study design, assumptions, experimental replicates and independently validated for publication.
  • Bioinformatics displays some precomputed outputs and does not replace dedicated pipelines for dimensionality reduction, enrichment, differential expression or phylogenetic inference.
  • The plotting app is browser-run; avoid assuming browser storage is permanent. Export important projects.
  • Exported images should be inspected at their final journal dimensions before submission.
