Welcome to Scientific Plot Studio

450 selectable chart/design combinations, 45 families and 10 coherent design presets. No sign-in, server or internet connection is required.

  1. Search or filter the plot library and choose a design.
  2. Upload CSV/TSV data or use the included sample datasets.
  3. Configure data mappings and appearance in the Figure editor.
  4. Export PNG, SVG, JPEG, WebP, PDF, interactive HTML or Plotly JSON.

Important: Plot families have different data requirements. Several specialized diagrams use demo-specific data transformations and assumptions. Scientific inference and statistics should be validated independently before publication.
